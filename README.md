# Life Food — Telegram Mini App

Frontend prototipi.

## Flow
1. Profil: ism, familiya, telefon
2. O‘zimga / Boshqaga
3. Maqsad: vazn tashlash / formani saqlash / vazn yig‘ish
4. Kaloriya
5. Individual / standart menyu
6. Stol raqami + geolokatsiya
7. Buyurtma xulosasi + karta / Click
8. Buyurtma qabul qilindi

## Keyingi bosqich
- Telegram WebApp SDK
- Backend/API va database
- Real menyu va narxlar
- Click/payment integratsiyasi
- Telegram bot bilan bog‘lash
- Admin panel va buyurtma statuslari
- Reverse geocoding va manzil tasdig‘i
